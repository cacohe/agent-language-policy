# Changelog

All notable changes to this project are documented in this file. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Changed

- Updated the installation and distribution documentation after the npm package and GitHub release became public.

## [0.1.0] - 2026-11-09

### Added

- Portable Agent Skill for human decision language rules.
- Persistent instruction support for Codex, Claude Code, Cursor, Gemini CLI, and GitHub Copilot.
- Project and user configuration, Markdown validation, safe updates, backups, status, diagnostics, and precise uninstall.
- Traditional Chinese (`zh-TW`) configuration, rendering, variant-aware validation, and documentation.
- Portable manifests for Codex, Claude Code, Gemini CLI, and Agent Plugins-compatible hosts.
- Apache-2.0 licensing, contribution guidance, security reporting, cross-platform CI, and deterministic package checks.
- Installation output that distinguishes persistent instructions from separately installed portable Skills and shows lifecycle commands.
