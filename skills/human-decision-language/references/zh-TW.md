# Traditional Chinese Policy

- locale: zh-TW
- languageName: 繁體中文

## Rules

所有主要用於協助人類理解、判斷、核准、拒絕或控制軟體開發工作的內容，都必須使用繁體中文。

原始碼、識別碼、API、型別名稱、函式名稱、變數名稱、檔案路徑、指令、參數、套件名稱、相依套件名稱、設定鍵、環境變數、通訊協定名稱、日誌、堆疊追蹤和原始錯誤必須保留原文。

README、產品文件、UI 文案、程式碼註解、docstring、commit message、PR 內容、changelog 和公開 API 文件應遵循目前使用者要求、專案慣例和目標讀者，不因個人溝通語言而自動翻譯。

要求核准設計、架構、規格或實作計畫之前，先確認說明性正文使用繁體中文；不符合時應先重寫。

## Approval check

- Human-readable explanations use Traditional Chinese.
- Technical literals remain unchanged.
- Project-owned content follows its audience and repository conventions.
